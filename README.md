# Thinking Creative

A responsive website for Thinking Creative, a mentorship program focused on essay writing, philosophical inquiry, argumentation, and intellectual development for junior and secondary-school students.

## Run locally

```bash
npm start
```

Then open http://localhost:3000.

## Deployment

This repository is configured for Railway. Railway will run `npm start` and provide `PORT` automatically.

The enquiry form currently opens the visitor's email client. Replace the placeholder recipient in `public/app.js` with the desired email address before using the form publicly.
